# LeetTrack 🚀

A minimalist and elegant LeetCode/DSA progress tracker built with Vanilla JavaScript.

LeetTrack helps developers track solved problems, maintain review lists, set future goals, and monitor coding consistency through an activity log.

## ✨ Features

### 📊 Progress Dashboard
- Total solved problems counter
- Difficulty-wise statistics
  - Easy
  - Medium
  - Hard
- Real-time updates

### 📝 Problem Tracking
- Add solved problems with:
  - Problem name
  - Problem number
  - Difficulty level
  - Confidence score
  - Personal notes

### 🎯 Goal Planning
- Schedule future problems as goals
- Mark goals as completed
- Separate planned and completed sections

### 🔄 Review System
- Mark problems for future revision
- Dedicated review indicators
- Filter review problems in activity logs

### 📅 Daily Tracking
- Navigate between dates
- Maintain coding history by day
- View progress across multiple days

### 📖 Activity Log
- Complete history of solved problems
- Difficulty-based filtering
- Review-only filtering
- Active days statistics
- Pending goals overview

### 💾 Local Storage Persistence
- Automatically saves data in browser
- No backend required
- Data persists between sessions

### 🌙 Dark Mode Support
- Automatically adapts to system theme
- Responsive modern UI
